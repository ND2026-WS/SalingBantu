Masuk Dulu untuk Mengajukan Bantuan

Agar pengajuanmu bisa dipantau dan diverifikasi dengan aman, diperlukan akun terlebih dahulu. Gratis, 2 menit selesai.

Masuk Daftar Akun Baru

Ajukan Bantuan

Ceritakan kebutuhanmu dengan jujur dan lengkap. Tim admin akan memverifikasi dalam 1-2 hari kerja.

Pilih kategori.

Pilih kebutuhan spesifik.

Judul wajib diisi (min. 10 karakter).

Deskripsi minimal 30 karakter agar mudah diverifikasi.

Isi 0 / kosong jika kebutuhan berupa barang atau tenaga.

Isi kota/kabupaten.

Isi nomor kontak aktif.

Klik untuk pilih foto (JPG/PNG, maks 2 MB)
Klik untuk pilih dokumen (PDF/JPG, maks 3 MB)

i Bagaimana Prosesnya?

  1. 1. Kirim pengajuan — isi form lengkap + foto/dokumen.
  2. 2. Verifikasi admin — status berubah menjadi Dalam Proses Verifikasi.
  3. 3. Dipublikasikan — pengajuanmu terlihat donatur publik.
  4. 4. Menerima bantuan — kamu menerima notifikasi setiap ada bantuan masuk.
  5. 5. Laporan penggunaan — bantu admin membuat laporan akhir agar tetap transparan.
Pengajuan palsu = penyalahgunaan amanah publik. Data identitas diminta admin bila diperlukan untuk verifikasi, dan tidak pernah ditampilkan publik.
